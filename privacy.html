Privacy policy

Command Center is a personal dashboard used by one person: its owner and developer. It is not offered to anyone else.

What data it accesses

  • Google Calendar (read-only): event titles, times and locations.
  • Gmail (read-only): sender, recipients, subject and Gmail's short preview of each message. Full message bodies are never downloaded.

How it is used and stored

The data is stored only on the owner's own computer and shown only to the owner, behind a password. It is never sold, and never used for advertising.

To sort email, the sender, subject and preview of messages are sent to Anthropic's Claude API for classification. No other third parties receive the data.

Command Center's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Email data covers the last 14 days, and calendar data a window of a few weeks. Access can be revoked at any time at myaccount.google.com/permissions, after which the stored data is deleted.
